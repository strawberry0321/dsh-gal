# 立绘包 / 语音包放这里

本目录（`assets/packs/`）是**插件内置**的包目录。插件安装后，宿主还会扫描一个
**用户目录**，它优先于这里、并且在插件升级时不会被覆盖：

```
%USERPROFILE%\.dsh\dsh-gal\packs\
```

## 一个包长什么样

```
<包名>/
├── pack.json          # 可选：显示名、默认立绘、裁切范围
├── sprites/           # 立绘（png / jpg / webp / gif / avif / bmp）
│   ├── large_neri_01face.png
│   └── ...
├── voices/            # 语音（wav / mp3 / ogg / m4a / aac / flac）
│   ├── ner0001.wav
│   └── ...
└── script.csv         # 可选：语音文件名 → 台词对照表
```

* 目录名就是**包 id**（设置面板里显示的就是它）。
* `sprites/` 与 `voices/` 可以只放其中一个：只放立绘就是一个「立绘包」，只放语音就是一个「语音包」。
* 立绘的透明边距会被自动裁掉，不需要自己切图。

## 默认立绘怎么定

对话框消失后立绘会切回**默认立绘**（也就是"常态姿势"）。规则只有两条：

| 优先级 | 怎么声明 |
|---|---|
| 1 | 在 `pack.json` 里写 `defaultSprite`，例如 `"defaultSprite": "01.png"` |
| 2 | **没写 → 系统自动选一张**：按**自然顺序**取第一张，所以 `2.png` 排在 `10.png` 前面 |

* 第 2 条保证**任何立绘包都一定有默认立绘** —— 你自己丢一堆图进去、什么配置都不写，也能正常工作。
* 文件名没有任何特殊含义：`Default.png` 只是一张普通立绘，不会因为叫这个名字就被选中。
* 设置面板的「立绘包」下面会写明当前用的是哪张、以及是 `pack.json 指定` 还是 `自动选定`。

## script.csv 的格式

第一行是表头，至少要能认出「文件名」和「日语」两列：

```csv
clip,chapter,speaker_jp,japanese,chinese,sec
ner0001,1,ねり,旅行、行こうよ！,去旅行嘛！,1.725
```

* `clip` 要和 `voices/` 里的文件名（不含扩展名）一致，例如 `ner0001` ↔ `ner0001.wav`。
* `japanese` / `chinese` 两列分别对应设置里的「日文 / 中文」。
* 字段可以用双引号包住，并且允许换行。
* 没有对照表也能用：此时没有台词可显示，点击立绘改为显示「余额 / 今日已用」，
  语音照常播放、立绘照常随机更换。

## pack.json（可选）

```json
{
  "displayName": "ねり（Neri）",
  "defaultSprite": "large_neri_01face.png",
  "crop": { "x": 0.164, "y": 0.168, "w": 0.679, "h": 0.832 }
}
```

* `displayName` — 设置面板里显示的名字，缺省时用目录名。
* `defaultSprite` — 默认立绘的文件名。**这是指定默认立绘的唯一方式**；写的文件不存在时
  会自动回退到自动选定，不会卡住。
* `crop` — 手动指定裁切范围（0~1 的比例）。**通常不需要写**：插件会自动扫描 PNG 的
  透明通道算出可见范围。只有当立绘是 JPG（没有透明通道）或自动裁切结果不满意时才需要手动指定。
